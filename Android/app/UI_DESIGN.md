# Дизайн главной оболочки приложения

## Назначение

`MainFragment` — постоянная визуальная оболочка приложения после выбора активного профиля. Она содержит верхнюю панель, шторку и нижнюю навигацию; содержимое вкладок открывается внутри неё.

## Верхняя панель и шторка

- В верхней панели слева находится кнопка-гамбургер, открывающая шторку.
- Заголовок: `Boss of This Gym`.
- Шторка показывает активный профиль и пункты:
  - «О себе»;
  - «Пользователи»;
  - «Настройки»;
  - «Справка».
- Пока модули не готовы, настройки и справка открывают собственные заглушки.

## Нижняя навигация

Нижняя навигация всегда содержит пять вкладок с иконками и постоянно видимыми подписями:

1. «Планы»;
2. «Создать»;
3. «Тренировка»;
4. «Календарь»;
5. «Вес».

Текущая вкладка визуально выделена. На первом этапе каждая вкладка открывает заглушку; позднее заглушки заменяются реальными экранами без изменения внешней оболочки.

## Навигационное поведение

- Внутри `MainFragment` работает дочерний навигационный граф для пяти вкладок.
- Повторное нажатие на текущую вкладку возвращает к её корневому экрану.
- Кнопка «Назад» сначала закрывает шторку или вложенный экран, затем работает по обычному стеку приложения.
