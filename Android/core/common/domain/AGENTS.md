# Контекст модуля `core:common:domain`

## Назначение
Чистый Kotlin/JVM-модуль с небольшими доменными типами, общими для нескольких частей приложения. Сейчас содержит `Resource<T>`.

## Правила
- Не использовать Android API, AndroidX, ресурсы или Hilt.
- Зависимости допускаются только от Kotlin/JVM-библиотек.
- При изменении структуры обновлять [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).
