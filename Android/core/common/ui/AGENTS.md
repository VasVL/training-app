# Контекст модуля `core:common:ui`

## Назначение
Android-модуль с общими UI-ресурсами, не принадлежащими конкретной фиче.

## Правила
- Хранить здесь только переиспользуемые UI-ресурсы.
- Не добавлять доменную логику, типы данных или навигацию.
- При изменении структуры обновлять [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).
