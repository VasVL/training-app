# Структура модуля `core/common`

> **Важно:** Этот файл нужно обновлять после изменений в структуре модуля (добавление/удаление папок, ключевых файлов).

## Обзор
Модуль `core/common` — общий переиспользуемый код: утилиты, расширения Kotlin, базовые классы (`Resource<T>`), константы. Не зависит от feature-модулей.

> **Текущее состояние:** модуль пока пустой — исходного кода в `src/main/java/` нет. Назначение (см. ниже) описывает планируемое содержимое. При появлении файлов — обновить этот раздел деревом.

## Структура
```
core/common/
├── .gitkeep                   ← Файл-заглушка (папка сохранена в git, пока нет исходников)
├── AGENTS.md                  ← Контекст модуля (назначение, архитектурные замечания)
├── build.gradle.kts          ← Конфигурация модуля (Android Library, Kotlin, зависимости)
├── MODULE_STRUCTURE.md       ← Этот файл
└── src/
    └── main/
        └── AndroidManifest.xml   ← Манифест библиотеки (минимальный, package declaration)
```

## Назначение (планируемое)
Модуль предназначен для общего кода, переиспользуемого между feature-модулями:
- `Resource<T>` — sealed class-обёртка для состояния данных (`Loading` / `Success(data)` / `Error(message, cause)`). Используется в Repository для предсказуемой обработки ошибок.
- Расширения Kotlin (extension functions) — переиспользуемые хелперы.
- Базовые классы/интерфейсы — общие для нескольких модулей.
- Константы — общие для всего приложения.

Папки под эти элементы (`resource/`, `extensions/`, `constants/`) будут созданы по мере появления кода.

## Правила
- При добавлении/удалении папки или ключевого файла — обновить этот файл (заменить раздел "Структура" фактическим деревом).
- Не зависеть от feature-модулей. Зависимости только от внешних библиотек и (при необходимости) других `core/*` модулей.
- Код должен быть максимально общим, без привязки к конкретным фичам.
