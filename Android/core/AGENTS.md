# Контекст папки `core`

## О папке
Папка `core/` — контейнер для общих модулей, переиспользуемых между feature-модулями. Содержит код, не привязанный к конкретной фиче: утилиты, навигация, база данных, сетевой слой и т.д.

Полное и актуальное описание внутренней структуры папки находится в файле **[`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md)**.

- **[`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md) нужно обновлять после любых изменений в структуре папки** — добавление/удаление модулей.
- Общие архитектурные/стилистические замечания для всего Android-проекта — в [`Android/AGENTS.md`](../AGENTS.md).

## Назначение
Общие модули, переиспользуемые между feature-модулями:
- `common/` — утилиты, расширения, базовые классы (`Resource<T>`), константы.

## Архитектурные замечания
- Модули из `core/` **не зависят от feature-модулей**. Зависимости только от внешних библиотек и (при необходимости) других `core/*` модулей.
- Feature-модули и `app` могут зависеть от `core/*`.
- Код здесь — максимально общий, без привязки к конкретным фичам.
- Реализации закрывать интерфейсами, инжектировать через DI (Hilt) по интерфейсу.
- `core/*` модули могут предоставлять адаптеры для портов, объявленных в `domain` feature-модулей (Ports & Adapters).
