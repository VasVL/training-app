# Контекст модуля `feature-auth:contract`

## Назначение

Чистый Kotlin-модуль с публичным API фичи пользователей. Другие фичи используют его для маршрутов auth и безопасных данных об активном профиле, не получая зависимости на Android UI, Room или реализацию репозитория.

Полная внутренняя структура находится в [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).

## Правила

- Маршруты `AuthScreen` размещать в корне пакета `contract`.
- Публичные модели размещать в `entity/`, а связанные enum — в `entity/type/`.
- Публичные интерфейсы доступа к возможностям фичи размещать в корне пакета `contract`.
- Не добавлять Android API, Room, XML-ресурсы, бизнес-логику и реализации доступа к данным.
- При изменении структуры обновлять [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).
