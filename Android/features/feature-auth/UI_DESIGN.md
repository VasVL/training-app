# Дизайн интерфейса feature-auth

> Утверждённые решения для экранов выбора пользователя и «О себе».
> Общие правила оформления — в [`Android/VISUAL_STYLE.md`](../../VISUAL_STYLE.md).

## Границы фичи

`feature-auth` позволяет:

- создать локальный профиль пользователя;
- отредактировать профиль;
- выбрать активного пользователя;
- открыть главный экран после выбора профиля.

Создание профиля не является регистрацией: аккаунт, адрес электронной почты и номер телефона не требуются. Данные сохраняются только на устройстве.

## Экран выбора пользователя

Экран открывается из пункта «Пользователи» в шторке главного экрана.

### Список пользователей

Если профили существуют, показывается прокручиваемый список.

Активный пользователь располагается первым, остальные — по имени. Ручная сортировка и перетаскивание не используются.

Каждая строка содержит:

- аватар с первой буквой имени;
- имя;
- роль;
- плашку с иконкой и текстом «Владелец» для пользователя с ролью `OWNER`.
- кнопку «⋮» с действиями «Редактировать» и «Удалить».

Активный пользователь дополнительно обозначается:

- тонкой контрастной рамкой;
- подписью «Активен сейчас»;
- иконкой галочки.

На корневом экране выбора пользователя стрелка «Назад» не показывается.

Добавление пользователя выполняется через `ExtendedFloatingActionButton` с иконкой плюса и текстом «Добавить».

Кнопка:

- скрывается при прокрутке списка вниз;
- появляется при прокрутке вверх;
- не перекрывает последний элемент списка благодаря нижнему отступу списка.

### Удаление пользователя

Удалить можно только неактивного пользователя с ролью `TRAINEE`. Перед удалением показывается диалог с заголовком «Удалить профиль „Имя“?» и пояснением, что вместе с профилем будут удалены все записи тренировок и измерения.

Владелец и активный пользователь не получают действие удаления в меню. Чтобы удалить активный профиль, сначала нужно выбрать другой профиль.

После подтверждения профиль исчезает из списка и на 5 секунд показывается Snackbar с текстом «Отменить удаление» и кнопкой «ОТМЕНИТЬ». До закрытия Snackbar профиль помечается как ожидающий удаления, но его данные остаются в базе. Кнопка «ОТМЕНИТЬ» снимает эту метку. После закрытия Snackbar профиль и связанные с ним данные удаляются окончательно.

Пользовательские программы и упражнения сохраняются: связь с удалённым автором обнуляется, чтобы эти шаблоны не исчезали из приложения.

### Выбор пользователя

Нажатие на пользователя делает его активным и открывает пустой `MainFragment`.

## Экран «О себе»

Экран является контейнером с вкладками `ViewPager2`:

- «Профиль» — форма личных данных;
- «Максимумы» — личные результаты по упражнениям. Название вкладки пока сохраняем для привычности интерфейса.

Общая `UserEditViewModel`, привязанная к контейнеру, хранит сессию редактирования обеих вкладок, общий признак несохранённых изменений и выполняет сохранение.

### Первый запуск

При первом запуске сразу открывается экран «О себе». Регистрация не требуется: аккаунт, номер телефона и электронная почта не нужны, а данные остаются на устройстве.

Первый пользователь автоматически получает роль `OWNER`. Обе вкладки видны сразу, но до первого сохранения вкладка «Максимумы» показывает пояснение «Сохраните профиль — затем можно добавить максимум».

После успешного сохранения первого профиля кнопка «Сохранить» меняется на «Продолжить». Она открывает главный экран. Если пользователь снова меняет данные, кнопка возвращается к тексту «Сохранить».

### Поля формы

Поля идут вертикально в прокручиваемом списке:

- имя;
- вес;
- рост;
- дата рождения;
- пол.

Имя — единственное обязательное поле и ограничено 40 символами: ограничение применяется в поле ввода и в валидации ViewModel. Роль в форме не выбирается: первый профиль получает `OWNER`, а профили, добавленные с экрана списка пользователей, — `TRAINEE`.

Вес и рост вводятся вручную с числовой клавиатуры.

- Допускается до двух знаков после запятой.
- Приложение принимает точку и запятую.
- Значение показывается в формате локали устройства.
- Единица измерения располагается справа внутри поля: например, `82,50 кг` или `180 см`.
- Ввод ограничен 7 символами вместе с десятичным разделителем; допустимый числовой диапазон дополнительно проверяется при сохранении.

Дата рождения выбирается через календарь. Рядом с ней показывается автоматически рассчитанный возраст, например: «14.08.1990 · 35 лет». Возраст не хранится отдельно и всегда соответствует текущей дате.

### Вкладка «Максимумы»

После сохранения профиля вкладка содержит прокручиваемый список личных результатов. В строке показываются упражнение, только нужные ему метрики и дата. Набор отображаемых полей определяется схемой результата упражнения: например, для планки показывается длительность, для бега на 100 м — время, для горизонта с жилетом — собственный вес, дополнительный вес и длительность.

При добавлении результата пользователь сначала выбирает упражнение, а форма строится по его неизменяемой схеме. Фиксированные значения упражнения показываются как пояснение и не редактируются. Расчётный результат помечается как оценочный и хранит исходные значения и формулу.

Для результата с собственным весом перед сохранением используется текущий вес пользователя. Если пользователь отказался от уточнения, применяется последнее сохранённое значение; выбранное значение сохраняется вместе с результатом.

Для добавления используется FAB «Добавить максимум». При прокрутке списка вниз FAB плавно скрывается, при прокрутке вверх — возвращается.

### Сохранение и выход

Общая кнопка нижней части контейнера сохраняет изменения обеих вкладок:

- закреплена внизу экрана;
- не скрывается при прокрутке;
- при корректных несохранённых изменениях показывает текст «Сохранить»;
- при ошибке формы остаётся видимой и неактивной;
- после сохранения первого профиля показывает «Продолжить»;
- при создании дополнительного профиля и редактировании существующего после сохранения скрывается; пользователь остаётся на текущей вкладке и возвращается кнопкой «Назад».

Если пользователь нажимает «Назад» с несохранёнными изменениями, появляется диалог:

- при корректной форме: «Сохранить и выйти», «Выйти без сохранения» и «Продолжить редактирование»;
- при ошибке формы, включая пустое обязательное имя: «Выйти без сохранения» и «Продолжить редактирование», а также пояснение «Имя нужно для сохранения профиля».

Если несохранённых изменений нет, возврат выполняется сразу. На первом запуске системная кнопка «Назад» закрывает приложение.

## Главный экран

После выбора пользователя открывается пустой `MainFragment`.

Этот Fragment является только точкой назначения навигации. Он не содержит интерфейса, пока главный экран приложения не реализован отдельной фазой.
