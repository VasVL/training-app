# Дизайн интерфейса feature-auth

> Утверждённые решения для экранов выбора пользователя и «О себе».
> Общие правила оформления — в [`Android/VISUAL_STYLE.md`](../../VISUAL_STYLE.md).

## Границы фичи

`feature-auth` позволяет:

- создать локальный профиль пользователя;
- отредактировать профиль;
- выбрать активного пользователя;
- открыть главный экран после выбора профиля.

Создание профиля не является регистрацией: аккаунт, адрес электронной почты и номер телефона не требуются. Данные сохраняются только на устройстве.

## Экран выбора пользователя

### Первый запуск

Если пользователей нет, показывается пустое состояние:

- заголовок «Выбор пользователя»;
- заголовок пустого состояния «Начнём с вашего профиля»;
- пояснение: профиль нужен для хранения тренировок и измерений на устройстве;
- заметный блок «Без регистрации»:
  - не нужен аккаунт, номер телефона или электронная почта;
  - данные сохраняются только на устройстве;
- центральная кнопка «Создать профиль».

Первый создаваемый пользователь автоматически получает роль `OWNER`.

### Список пользователей

Если профили существуют, показывается прокручиваемый список.

Каждая строка содержит:

- аватар с первой буквой имени;
- имя;
- роль;
- плашку с иконкой и текстом «Владелец» для пользователя с ролью `OWNER`.

Активный пользователь дополнительно обозначается:

- тонкой контрастной рамкой;
- подписью «Активен сейчас»;
- иконкой галочки.

На корневом экране выбора пользователя стрелка «Назад» не показывается.

Добавление пользователя выполняется через `ExtendedFloatingActionButton` с иконкой плюса и текстом «Добавить».

Кнопка:

- скрывается при прокрутке списка вниз;
- появляется при прокрутке вверх;
- не перекрывает последний элемент списка благодаря нижнему отступу списка.

### Выбор пользователя

Нажатие на пользователя делает его активным и открывает пустой `MainFragment`.

## Экран «О себе»

Один экран используется для создания и редактирования профиля.

### Поля формы

Поля идут вертикально в прокручиваемом списке:

- имя;
- роль;
- вес;
- рост;
- возраст;
- пол.

Вес и рост вводятся вручную с числовой клавиатуры.

- Допускается до двух знаков после запятой.
- Приложение принимает точку и запятую.
- Значение показывается в формате локали устройства.
- Единица измерения располагается справа внутри поля: например, `82,50 кг` или `180 см`.

При создании первого пользователя роль отображается как неизменяемый блок «Владелец».

При создании следующих пользователей роль выбирается между `OWNER` и `TRAINEE`.

Разовые максимумы не входят в текущий этап.

### Сохранение и выход

Кнопка «Сохранить»:

- закреплена внизу экрана;
- видна всегда;
- не скрывается при прокрутке;
- неактивна, пока данные не изменены или форма содержит ошибку;
- становится активной только после корректного изменения данных.

Если пользователь нажимает «Назад» с несохранёнными изменениями, появляется диалог:

- заголовок «Не сохранять изменения?»;
- текст «Изменённые данные профиля будут потеряны.»;
- действия «Остаться» и «Не сохранять».

Если несохранённых изменений нет, возврат выполняется сразу.

## Главный экран

После выбора пользователя открывается пустой `MainFragment`.

Этот Fragment является только точкой назначения навигации. Он не содержит интерфейса, пока главный экран приложения не реализован отдельной фазой.
