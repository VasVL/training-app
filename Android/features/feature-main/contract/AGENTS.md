# Контекст модуля `feature-main:contract`

## Назначение

Чистый Kotlin-модуль с публичным описанием маршрута главной оболочки. Его используют другие модули, не получая зависимости на Android UI или реализацию главной фичи.

Полная внутренняя структура находится в [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).

## Правила

- Хранить здесь только публичные контракты главной фичи: маршруты и их аргументы.
- Не добавлять Android API, ресурсы, бизнес-логику, реализации или доступ к данным.
- При изменении структуры обновлять [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).
