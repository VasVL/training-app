# Контекст модуля `feature-main:ui`

## Назначение

Android UI-модуль главной оболочки приложения: `MainFragment`, `MainViewModel`, XML-разметка, UI-состояния и одноразовые UI-действия. Это владелец нижней навигации и шторки.

Полная внутренняя структура находится в [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).
Утверждённый дизайн находится в [`../UI_DESIGN.md`](../UI_DESIGN.md), технический макет — в [`../UI_MOCKUPS.html`](../UI_MOCKUPS.html).

## Правила

- `MainFragment` только отображает состояние, привязывает UI-компоненты и отправляет намерения во ViewModel.
- `MainViewModel` получает данные через domain-сценарии и публичные контракты; не обращается к Room напрямую.
- `UiState` и UI-сущности не используют domain-модели напрямую.
- Каждый экран сразу размещать в отдельном экранном пакете, даже если он пока единственный; Fragment оставлять в корне пакета, а `entity`, `mapper` и `viewmodel` — в подпапках.
- `MainFragment` владеет только локальным дочерним NavController пяти вкладок и временных заглушек. Межфичевые переходы инициирует `MainViewModel` через публичные контракты и общий `Navigator`.
- При изменении структуры обновлять [`MODULE_STRUCTURE.md`](MODULE_STRUCTURE.md).
