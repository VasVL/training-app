# Системный экран запуска

## Цель

Не показывать пустой главный экран, пока приложение определяет, есть ли активный профиль.

## Решение

- Использовать `androidx.core:core-splashscreen` для системного splash-экрана на Android 7.0 и новее.
- Экран запуска остаётся видимым, пока `MainActivity` получает активный профиль из `UserRepository`.
- При отсутствии активного профиля открыть создание первого профиля без возврата на пустой главный экран.
- При наличии активного профиля открыть главный экран.
- Отдельный `SplashFragment` не создавать: он не содержит самостоятельного UI и только усложнил бы back stack.

## Границы

Системный splash не заменяет пендинг конкретных экранов. После выбора точки назначения каждый экран продолжает сам отображать свои состояния `Loading`, `Error` и `Ready`.
